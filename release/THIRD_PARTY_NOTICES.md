# Provenance and dependencies

The packaged Prospice.Placement.dll is built from this repository's C# mod source. No game code binaries, Unity assets, recovered metadata, generated game bindings, saves, configuration or third-party runtime DLLs are included.

External prerequisites, installed separately:

- Prospice Demo and its Unity 2022.3.62f2 engine: proprietary game/engine materials, retained in the user's game installation.
- BepInEx 6.0.0-be.788+5b766a3, Il2CppInterop 1.5.3.0 and HarmonyX 2.10.2.1: supplied by the separately installed loader. Retain the notices and licenses in those upstream distributions.
- Microsoft .NET 6.0.7: supplied with the loader. The build SDK is .NET 8.0.425 and is not shipped here.
